В ходе выполнения курсовой работы было спроектировано и реализовано веб-приложение для учета базы клиентов и проведения опросов. Разработанное приложение представляет собой полнофункциональную систему, объединяющую управление клиентской базой и создание опросов в едином программном продукте.
 
Основные результаты работы:
 
1. Проведен анализ предметной области, в результате которого выявлены основные требования к системе. Установлено, что существующие решения не предоставляют интегрированной связи между клиентской базой и результатами опросов, что подтверждает актуальность разработки.
 
2. Обоснован выбор архитектуры (трехуровневая клиент-серверная) и технологического стека: React для фронтенда, Node.js + Express для бэкенда, PostgreSQL для базы данных. Выбор обоснован производительностью, масштабируемостью, бесплатностью и наличием документации.
 
3. Спроектирована реляционная база данных, включающая пять таблиц: users (пользователи), clients (клиенты), surveys (опросы), responses (ответы), user_actions (действия). Определены связи между таблицами, созданы индексы для ускорения поиска.
 
4. Разработана серверная часть, реализующая REST API с эндпоинтами для аутентификации, управления клиентами, управления опросами и логирования. Реализована JWT-аутентификация, хеширование паролей, валидация входных данных.
 
5. Разработана клиентская часть на React, включающая компоненты для авторизации, дашборда, управления клиентами, конструктора опросов, прохождения опросов, просмотра результатов и профиля пользователя. Интерфейс адаптирован для мобильных устройств.
 
6. Реализованы все заявленные функции: регистрация и вход пользователей; полный цикл управления клиентами (CRUD) с поиском; конструктор опросов с тремя типами вопросов и перетаскиванием; прохождение опросов с прогресс-баром и валидацией; визуализация результатов; логирование действий пользователей.
 
7. Проведено тестирование серверной и клиентской частей, подтвердившее корректную работу всех функций, корректную обработку ошибок и адаптивность интерфейса.
 
Практическая значимость работы заключается в создании готового к использованию программного продукта, который может быть внедрен в деятельность малых и средних предприятий, образовательных учреждений и некоммерческих организаций для сбора обратной связи, проведения маркетинговых исследований и оценки удовлетворенности клиентов.
 
Направления дальнейшего развития включают:
- Добавление новых типов вопросов (множественный выбор, матричные вопросы, загрузка файлов).
- Возможность брендирования опросов (логотип, цветовая схема).
- Интеграцию с почтовыми сервисами для автоматической рассылки опросов.
- Экспорт отчетов в PDF и Excel.
- Создание мобильного приложения на React Native.
- Внедрение искусственного интеллекта для анализа текстовых ответов.
- Многопользовательский режим с разграничением доступа по ролям.
 
Все поставленные задачи выполнены, цель работы достигнута. Разработанное приложение готово к эксплуатации.
